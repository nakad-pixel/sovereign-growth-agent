# Skill: short_form_story_with_lead_cta

## When to use
- Promote a free high‑value lead magnet (e.g., guide, checklist) on high‑reach channels (Telegram, Twitter, etc.).
- Need a quick, low‑cost post to capture leads or drive affiliate clicks.
- Must comply with rules: clear CTA, valid link, no false claims, concise copy.

## Steps
1. **Hook**: Start with a friendly emoji and greeting (e.g., 👋 Hello!).
2. **Value statement**: Mention the free resource and its benefit in one sentence.
3. **CTA**: Add a direct call‑to‑action with an arrow emoji and a short, working URL.
4. **Compliance check**: Verify the link works, no income claims, copy ≤ 200 characters.
5. **Publish**: Send via the chosen channel using the `telegram_manual` template.

## Pitfalls
- Missing or broken URL.
- Overly long copy that dilutes the CTA.
- Any mention of guaranteed earnings or false scarcity.
- Using generic or unrelated hashtags that reduce relevance.

## Example
```
👋 Hello! Ready to automate your home services? Grab our free 5‑Step Blueprint now 👉 https://example.com/free-guide
```
